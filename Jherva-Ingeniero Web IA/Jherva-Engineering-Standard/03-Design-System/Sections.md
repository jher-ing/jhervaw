# Secciones

## Principio general
Cada sección de una página (hero, features, testimonios, pricing, footer) sigue una estructura y espaciado predecibles para dar ritmo visual consistente a la página.

## Estructura estándar de sección
```
[Espaciado vertical superior]
  [Eyebrow/label opcional]
  [Título de sección]
  [Subtítulo/descripción opcional]
  [Contenido principal: grid, cards, formulario]
  [CTA opcional]
[Espaciado vertical inferior]
```

## Reglas
- Padding vertical consistente entre secciones (`--space-16` a `--space-24` en desktop, reducido en mobile).
- Ancho máximo de contenido (`max-width: 1200px` o similar) centrado, con padding lateral en mobile.
- Alternar fondos (blanco/gris claro) para separar secciones visualmente sin depender solo de espaciado.
- Cada sección tiene un solo mensaje/objetivo claro — no mezclar 3 ideas en una misma sección.

## Checklist rápido
- [ ] ¿El espaciado vertical entre secciones es consistente en toda la página?
- [ ] ¿Cada sección comunica una sola idea principal?
- [ ] ¿El contenido respeta un ancho máximo legible en pantallas grandes?
