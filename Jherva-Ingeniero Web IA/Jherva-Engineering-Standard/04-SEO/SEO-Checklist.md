# Checklist General de SEO

## Antes de lanzar

### On-page
- [ ] Un solo `<h1>` por página, jerarquía de encabezados correcta.
- [ ] Title y meta description únicos y optimizados en cada página.
- [ ] URLs limpias, descriptivas, en minúsculas, con guiones.
- [ ] Imágenes con `alt` descriptivo.
- [ ] Canonical tags correctos en todas las páginas.

### Técnico
- [ ] HTTPS activo, sin contenido mixto.
- [ ] Sitemap.xml generado y enviado a Search Console.
- [ ] Robots.txt correctamente configurado (staging bloqueado, producción abierta).
- [ ] Core Web Vitals en verde (ver `06-Performance/Core-Web-Vitals.md`).
- [ ] Sitio 100% responsive, mobile-first indexing validado.
- [ ] Sin errores 404 en enlaces internos.
- [ ] Redirects 301 (no 302) en URLs migradas.

### Structured Data
- [ ] Schema.org implementado según tipo de contenido (`LocalBusiness`, `Article`, `FAQPage`, etc.).
- [ ] Validado con Rich Results Test.

### Social
- [ ] Open Graph e imagen OG configurados por página.
- [ ] Twitter Card configurada.

### Contenido
- [ ] Keyword principal identificada por página, sin keyword stuffing.
- [ ] Contenido original, sin duplicados internos ni externos.
- [ ] Enlazado interno hacia páginas relacionadas y de conversión.

## Post-lanzamiento
- [ ] Sitio verificado en Google Search Console y Bing Webmaster Tools.
- [ ] Google Analytics / herramienta de analítica instalada y verificada.
- [ ] Monitoreo de posiciones para keywords objetivo configurado.
