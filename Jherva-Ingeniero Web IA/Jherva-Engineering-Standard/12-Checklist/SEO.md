# Checklist: SEO (Pre-Lanzamiento)

- [ ] Title y meta description únicos en cada página.
- [ ] Un solo `<h1>` por página con jerarquía de encabezados correcta.
- [ ] URLs limpias, descriptivas y en minúsculas.
- [ ] Canonical tags configurados correctamente.
- [ ] Sitemap.xml generado dinámicamente y enviado a Search Console.
- [ ] Robots.txt configurado (staging bloqueado, producción abierta).
- [ ] Imágenes con `alt` descriptivo.
- [ ] Schema.org implementado según tipo de contenido.
- [ ] Open Graph e imagen social configurados por página.
- [ ] Redirects 301 en cualquier URL migrada desde una versión anterior del sitio.
- [ ] Core Web Vitals en verde (ver `06-Performance/Core-Web-Vitals.md`).

Checklist completo y detallado en `04-SEO/SEO-Checklist.md`.
