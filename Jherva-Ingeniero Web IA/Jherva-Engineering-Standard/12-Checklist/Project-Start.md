# Checklist: Inicio de Proyecto

## Definición
- [ ] Objetivo del proyecto y métricas de éxito definidas (¿qué significa "funcionó"?).
- [ ] Público objetivo y caso de uso principal claros.
- [ ] Alcance del MVP definido — qué SÍ y qué NO se construye en esta fase.

## Arquitectura
- [ ] Stack tecnológico definido (ver `01-Architecture/Architecture.md`).
- [ ] Estructura de carpetas inicial creada (ver `01-Architecture/Folder-Structure.md`).
- [ ] Modelo de datos inicial esbozado.

## Configuración base
- [ ] Repositorio creado con `.gitignore` correcto (incluye `.env*`).
- [ ] `.env.example` con variables necesarias documentadas.
- [ ] Convenciones de naming y commits acordadas (ver `01-Architecture/Naming-Conventions.md`).
- [ ] CI configurado desde el primer PR (lint, types, build) — ver `10-Deployment/CI-CD.md`.
- [ ] Ambientes de development/preview/production definidos (ver `10-Deployment/Environment.md`).

## Diseño
- [ ] Tokens base del sistema de diseño definidos: colores, tipografía, espaciado (ver `03-Design-System/`).
- [ ] Referencias visuales/moodboard acordadas con el cliente/stakeholder.

## Legal y contenido
- [ ] Política de privacidad y términos de servicio (si aplica) contemplados desde el inicio.
- [ ] Contenido real (o placeholder claramente marcado) disponible antes de construir UI final.
